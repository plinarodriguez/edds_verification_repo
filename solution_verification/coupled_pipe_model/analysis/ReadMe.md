# Analysis - Coupled Pipe Model Solution Verification

This directory contains the post-processing workflow used to convert OpenFOAM simulation outputs (VTK) into **CSV datasets**, compute verification metrics, and generate **publication-quality figures**. The analysis is designed to be reproducible from the contents of this Git repository using a csv data file and not the simulation output files since they are large VTK files.

## Directory content

- `scripts/`: Analysis and plotting scripts. Scatter plots generated by `contour_plots.py` and the order of convergence plot is generated by `l2norm_streeq.py`. Note that the `l2norm_streeq.py` requires that the StREEQ analysis be completed first.
- `data/`: Processed, analysis-ready CSV outputs derived from VTK results. These CSVs are the results used to make plots and compute metrics.
- `figs/`: Figures generated by the scripts
- `streeq_studies/`: Extrapolation studies using StREEQ for the same Quantity of Interest (QoI) given the study was co-refined. 
    1. `Tbulk_mesh/`: Spatial Resolution vs. QoI 
    2. `Tbulk_time/`: Temporal Resolution vs. QoI 

## Inputs to the analysis

The analysis expects simulation results exported to VTK format for the fluid and solid region ( `pipeFluid` and `caseSolid`). The VTK file format is converted to csv data files using the python script `data_process_VTK-CSV.py`. This is a step that is expected before beginnning the analysis in this directory and after the simulation has produced output results. 

## Workflow

1. **Run the simulation** (from the case directory) and ensure VTK output has been generated
2. **Extract CSV data from VTK** using the python script `data_process_VTK-CSV.py`
3. **Convert CSV data to StREEQ format** Convert the CSV data to StREEQ format by prepending # to the header row, and keeping only two columns, resolution in column 1 and the QoI in column 2. 
4. **Run StREEQ**: This requires a `YAML` file that is run in the command line with `streeq filename.yaml` . Note that StREEQ must be installed to do this step.
5. **Compute metrics & Generate figures** Using the StREEQ output extrapolated QoI and statistics, figures are generated.
