# Meshes

In order to run this Dakota study the meshes need to be generated and then added to this directory 

They must be listed in this format so that the Dakota workflow could read in the correct files: 

- mesh0.msh (coarsest mesh)
- mesh1.msh
- mesh2.msh
- mesh3.msh (nominal mesh used for tolerance and time step study)
- mesh4.msh
- mesh5.msh
- mesh6.msh (finest mesh)
